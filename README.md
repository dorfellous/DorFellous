# Palmer-Inspired Portfolio Template

A clean static website inspired by the Palmer Framer template mood: dark editorial layout, oversized typography, image-led project rows, services, testimonials, pricing, and contact.

## Files

- `index.html` - page structure
- `styles.css` - responsive visual system
- `script.js` - smooth anchor navigation

## Use On GitHub Pages

1. Create a GitHub repository.
2. Upload these files to the repository root.
3. Go to **Settings > Pages**.
4. Set the source to your main branch and root folder.
5. Open the generated GitHub Pages URL.

## Customize

Replace the name, text, email, pricing, and image URLs in `index.html`. The site uses remote Unsplash images so it works immediately without an asset folder.
